## Method and limits

- **Discovery:** `git ls-files` for `*.test.ts`, `*.spec.ts`, `*.e2e.ts`. **385 test files** (re-measured 2026-11-26): 216 `.unit.`-suffixed, 107 `.integration.`, 41 `.smoke.`, 9 Playwright `.e2e.ts`, 0 `.canary.`, plus 12 not matching a layer suffix (content/fixture/support tests).
- **Not measured:** per-test runtime and line/branch coverage. CI now runs the unit job with `--coverage --coverage-reporter=lcov`, but no lcov figure has been read in this phase; the speed criterion is therefore **unverified** and no test is bucketed on speed.
- **Bucketing is by file group**, using layer suffix, owning module and a name-based sibling check (source file `x.ts` has a `x.*test.ts` next to it, or its module is imported by some test). Individual test bodies were not read. Treat per-file calls as approximate; the group totals are the reliable part.
- **Unverified claims from Phase 2:** the blueprint's "to create" helpers were not checked for existence one by one. `chat/src/test-fakes.ts`, `admin/src/*.fixtures.ts` and `runtime/fixtures/stream-json/` do exist.
